# Hexvault

An original **HD pixel-art, anime-RPG style** top-down action roguelite built with **Godot 4.7.2** and GDScript.
Dive through procedurally generated floors of a clockwork arcane vault, collect weapons and
boons, defeat elites and the boss **Ossifex, the Clockwork Lich**, then return to the Sanctum
to unlock heroes, weapons and permanent upgrades.

Everything — code, pixel art, font, sound effects and music — was created for this project
(art and audio are generated by deterministic scripts in `tools/`). Fully offline, no accounts.

## Features

- **12 heroes in 12 classes**, each with its own active skill, passive, starting weapon,
  silhouette and anime face: Vex (Overclock / Deadeye), Bramble (Bulwark / Stonehide),
  Nyx (Phase / Hexblood), Cog (Deploy / Scrap Rush), Kaida (Whirlwind / Riposte),
  Ignis (Flame Nova / Kindling), Rime (Glacial Field / Shatter), Volt (Thunderhead / Static),
  Morrow (Raise Wisps / Soul Harvest), Sable (Veil / First Strike), Halvard (Sanctuary /
  Devotion), Brixa (Barrage / Big Bang). Data-driven: a new hero is JSON + two small scripts +
  an art module (see [docs/ADDING_CHARACTERS.md](docs/ADDING_CHARACTERS.md)). Per-hero mastery
  levels; Hero Shrine with paging, archetype filter, sorting and search.
- **HD pixel art** (density 4: 128 px hero frames, 64 px tiles) generated by deterministic
  scripts, with an art style guide and automated asset QA ([docs/ART_STYLE_GUIDE.md](docs/ART_STYLE_GUIDE.md)).
- **14 data-driven weapons** across 9 categories: pistol, shotgun, assault rifle, sniper
  (hitscan, piercing), bow, melee (deflects bolts), magic (homing), explosive, experimental
  (frost needler, chain lightning, refracting beam). Rarity, crits, magazines/reloads,
  elemental status effects (burn, frost slow, shock stun, hex vulnerability).
- **5 enemy archetypes** with a finite-state-machine AI (chaser, ranged kiter, flanker,
  charging tank, summoner) + elite variants with extra tricks.
- **Boss** with 3 phases, 7 telegraphed attack patterns, phase transitions, health bar.
- **Procedural floors**: seeded, deterministic, constrained generation with validation and
  fallback; start / combat / elite / treasure / shop / healing / event / exit / boss rooms.
- **Progression**: shards, permanent upgrades (Rune Forge), weapon & hero unlocks,
  10 achievements, tiered quest lines, run boons, Heroic difficulty after first win.
- **Robust saves**: versioned, checksummed, atomic writes, automatic backup, corruption
  recovery, schema migration.
- **Controls**: keyboard + mouse, gamepad, and mobile touch (virtual stick, aim pad,
  skill/dash/swap/use buttons, UI scale/opacity, safe areas, aim assist).
- **Game feel**: hit flash, screen shake (adjustable), hit-stop, damage numbers, muzzle flash,
  impacts, explosions, death effects, dash ghosts; reduced-effects mode.

## Running

From source (Windows): download Godot 4.7.2 as described in [BUILD_GUIDE.md](BUILD_GUIDE.md), then

```bash
.tools/Godot_v4.7.2-stable_win64.exe --path .          # play
.tools/Godot_v4.7.2-stable_win64.exe --path . -e       # open the editor
```

Packaged builds: `build/Hexvault-0.9.0-windows-x64.zip` (run `Hexvault.exe`),
`build/android/hexvault-debug.apk` (`adb install -r ...`). See the build guide to produce them.

## Project layout

```
assets/        generated sprites, tiles, font, icons, audio + manifest.json
data/          weapons, characters, enemies, progression, room templates (JSON)
scenes/        main.tscn (everything else is composed in code)
scripts/
  autoload/    Events, Db, SaveManager, Profile, Settings, Controls, SpriteLib, Sfx, Game
  core/        Health, Hurtbox, HitInfo, Damage, StatusEffects, SaveStore, RunState
  combat/      Weapon, Projectile(+Pool), Combat (explosions, hitscan, chain, melee)
  dungeon/     DungeonGenerator, DungeonLayout, RoomTemplate
  world/       Level, LevelBuilder, Room, Tiles, dungeon_floor + hub screens
  entities/    Player, Enemy, Boss, pickups, chests, shop, portal, props
  ui/          HUD, minimap, touch controls, menus, panels, theme
  fx/          FX helpers, camera, telegraphs
tests/         unit + integration + end-to-end tests (mini runner)
tools/         art/audio generators, asset validator, check.py, package.py
```

## Development

```bash
python tools/check.py            # asset validation + asset QA + import + 58 automated tests
python tools/artgen/build.py     # regenerate art
python tools/audiogen/build.py   # regenerate audio
```

Agent skills used during development live in `.claude/skills/` (see
[DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md#agent-skills)). They can be managed with the
open skills CLI (`npx skills list`) or edited directly.

## Known limitations

- **iOS**: export preset configured, but no iOS build was produced (requires macOS + Xcode).
- Android verified on an emulator (API 37, x86_64) only — not yet on a physical phone.
- Gamepad support is implemented but was not tested with physical hardware.
- No key-rebinding screen yet; no localisation (English only).
- One biome and one boss; balance is a first pass. Several enemies, props and FX are still
  16 px art (shown 4x) next to the HD heroes, golem and tiles - see DEVELOPMENT_STATUS.md.
- Mid-run save/resume is intentionally not implemented (permanent progress and settings are saved).
- Saves are local only; there is no cloud sync.

Full status, test evidence and next steps: [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md).
